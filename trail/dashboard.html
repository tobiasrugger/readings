Teacher password

Who wrote it — devices and word flags

What this shows

Every browser that opens a student page gets its own device code (like K7Q2-M9XD). It stays on that computer. Each time a student page saves, the code is written down with the student, the page, the period and the time.

🚩 Word flags: saved text is checked against a short list of bad words in English, Spanish, Chinese, Arabic, Vietnamese, Thai and Nepali. A match shows here. The student sees nothing, and nothing is blocked or deleted.

Students are not told about this unless you switch the note on below. Tap a device code to see every student who used it; tap a name to see every device they used. Counting started Nov 2026 (T-337).

🖥️ The note in sign-in boxes

When it is on, every student sign-in box shows one small line, in the student’s language: “Mr. Toby can see which computer saves your work. Please sign in only as yourself.” The trail records either way.
