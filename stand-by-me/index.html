The text is not in the repo. part1.html and part1a.html load the novella excerpt from a block inside the file or from a paste saved on the device. Paste it into the marked block before you upload, and every student gets it without doing anything.

Before students sign in:

  1. Run the sbm_work schema in the Supabase SQL editor if you haven’t — the character project writes there. The unique index must be on plain columns, not lower(...).
  2. Open characters.html → Teacher tab and paste the portrait and clip URLs.
  3. Scrub the clip timestamps in vocab.html and characters.html against your copy of the film. Both sets are approximate.
  4. Teacher dashboard password stays galileo2026.

Where the work is saved. The character project writes to Supabase. The four reading and vocabulary pages save to the device with localStorage — fine for a one-sitting handout or a printed packet, but a student who switches devices starts over. Say the word and they can be moved onto Supabase with a dashboard like the Manzanar one.

Print. Every page in the folder has a blank-copy print and an answers print. This hub prints as a one-page unit map with the teacher notes stripped out.
