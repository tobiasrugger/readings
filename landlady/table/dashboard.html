Word translations for the Reader (do this once)

The story has about 550 words worth translating. This asks the translator for each one, in the languages you tick, and saves them so every tap in class is instant. It runs in this tab (about 15–20 minutes for 5 languages); leave the tab open. Words already saved are skipped, so you can stop and run it again. Anything it misses is translated the first time a student taps it.
