Teacher sign-in

Cell = best attempt as a mark out of 4 (4 = 90%+, 3 = 75–89, 2 = 60–74, 1 = anything started, 0 = nothing right; ✓ = done but the activity reports no number). Press Show percents to switch back. A dotted outline means a completion score: parts done over parts on the page, for activities with no quiz number. Hover a cell for attempts and date. Click an activity header to copy that column for Synergy in roster order. Change a student's period with the dropdown in their row; it saves. Sort order inside a period = roster order if set, else last name.

Compare sheet — what the site has

Print it, open Synergy beside it, and write what Synergy shows in the empty box. Tick the line when the two agree.

What changed — marks to type into Synergy

Tick each line as you type it — ticks are saved for this period, so you can finish on the other computer. Press Entered in Synergy \u2713 only when the whole period is done — next time the list starts from that moment, so you only ever see what is new.

Synergy export — one number for every student

Every student in the current filter gets a number — no ticks, no blanks unless you ask for them. In Synergy, click the first student’s cell in that column and paste. Copy names first if you want to check the roster order.
