Check everything, now

Walks every page the grid knows about, fetches each one live, and re-runs the checks. Rows that disagree with the saved grid are marked changed — that is drift since the last scan. Nothing is written anywhere; use Download fresh data to hand the result back for a rebuilt grid.

No English only = the language list in the sign-in box has no "English only" choice (project rule). Toolbar pickers outside the box, "Instructions: English only" toggles and the "You chose English only" message don't count. Chrome translate off = Chrome's own page translation can't change the English (translate="no" on <html>, the notranslate meta, or track.js); teacher pages are n/a. Loads first = the page reads the student's saved work before it writes any (saveguard.js, or the page's own inline guard). Robot = the last run of readings/robot/robot.py, which drives a real browser through three situations: a fresh Chromebook with work saved under the other email spelling, the server down, and a shared Chromebook. It can't drive recording pages, and a page it has never visited shows N/A rather than a pass.
